# MTH321 Project 2 — Mixed-Boundary Poisson Problem

Group N's finite-difference study of a Poisson equation on the unit square with Dirichlet data on three sides and Neumann or Robin data on the open right edge. The report compares a first-order backward-difference boundary row with a ghost-point boundary PDE closure.

## Submission files

| Path | Contents |
|---|---|
| `report/MTH321_project2.pdf` | Full group report |
| `slides/` | Group presentation files |
| `code/` | Solver, experiments, figure generation, and 16 automated tests |
| `data/` | Saved CSV results and `run_metadata.json` for the archived numerical run |
| `figures/` | Figures used in the report |
| `generated/` | Generated LaTeX tables and numerical values used in the report |
| `RESULTS_SUMMARY.md` | Short summary of the saved numerical results |
| `requirements.txt` | Pinned dependencies for the archived run |

The archived results were generated with Python 3.13.5, NumPy 2.1.3, SciPy 1.15.3, Matplotlib 3.10.0, and scikit-fem 12.0.2 on Windows 11. The precise settings and solver choice are in `data/run_metadata.json`. A later independent verification described in the report used a different Python/library environment; its version numbers are not those of the archived result files.

## Reproduce the numerical study

From the repository root, using a compatible Python 3.13 environment:

```bash
python -m pip install -r requirements.txt
python code/run_all.py
python -m unittest discover -s code/tests -v
```

`code/run_all.py` regenerates `data/`, `figures/`, `generated/`, and `RESULTS_SUMMARY.md`. It also remeasures timings, so timing values and cost ratios can differ by machine and run. The submitted files should be read as one consistent archived run; avoid mixing only part of a new run with them.

The report's mathematical analysis and prose are in the PDF; its complete LaTeX source is maintained in Overleaf and is not part of this repository. The presentation directory is not generated by `code/run_all.py`.
