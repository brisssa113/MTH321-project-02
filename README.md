# MTH321 Project 2 numerical experiments

This package contains the mixed-boundary Poisson implementation and its numerical evidence, plus separate depth and variable-diffusion comparisons. It includes the complete report source (`main.tex`), the compiled 66-page report (`MTH321_project2_report.pdf`), and the results summary (`RESULTS_SUMMARY.md`). The main experiments cover both right-edge closures with Neumann and Robin data, refinement through N=512, matrix and energy checks, direct/GMRES/CG comparisons, an independent FEM check, and a pure-Neumann extension. The added all-Dirichlet benchmarks compare sparse direct with Jacobi, FDM with P1 FEM, and smooth with corner-singular solutions on an L-shaped domain.

## Reproduce

Use Python 3.12 or 3.13 from this folder with the pinned package versions:

```text
python -m pip install -r requirements.txt
python -m unittest discover -s code/tests -v
python code/run_all.py
```

`code/run_all.py` is the full numerical reproduction entry point. It regenerates the mixed-boundary, depth-comparison and variable-diffusion CSV files, plots and report fragments. The separate unit-test command runs 22 tests. Exact run environments are recorded in `data/run_metadata.json` and `data/depth_extension/run_metadata.json`. Timings vary across machines and runs. The historical five-gate audit in `audit/` is a separate, retained October 22 record and is not regenerated by this command.

## Overleaf integration

The report fragments are not standalone documents. The Overleaf root uses `\input{depth_extension}` and `\input{variable_diffusion}` after the original mixed-boundary experiments. The final submission ZIP contains those root report files, their figure and data dependencies, the Python source and the retained audit material. The square all-Dirichlet and L-shaped results are separate benchmarks; do not substitute them into the original mixed-boundary FO/G tables. The L-shaped singular solution is continuous but nonsmooth, not discontinuous.

## Further checks

Variable diffusion is a separate all-Dirichlet benchmark: the prescribed sine test with smooth `a=1+x` uses matched FDM/FEM meshes, while the discontinuous two-layer case compares harmonic and arithmetic face means on an interface-aligned FDM grid. The latter includes a contrast sweep, whole-interface flux diagnostics, a solution cut and three figures. The L-shaped study retains `lshape_quadrature.csv` and `lshape_solver_check.csv`, plus two mesh images. The order-12 to order-19 singular energy error changes by about 0.22%, so the convergence trend is more reliable than all printed digits.


## Current revision and saved validation

`RESULTS_SUMMARY.md` is the results index at the package root. `validation/` contains unit-test and clean full-entry execution logs. The current suite has 16 original tests plus six variable-diffusion tests. Historical audit counts are unchanged.

`python code/run_all.py --check-inputs` checks mandatory theory sources before any numerical experiment. The full entry regenerates root and report copies consistently. Keep `report/lshape_theory.tex` and `report/variable_diffusion_theory.tex` in the package; edit these sources for theory changes.

The variable sine CSV records matrix symmetry defects. `sine_fitted_orders.csv` records log-log fits on N=16,32,64. `interface_flux_profiles.csv` stores crossing and independently reconstructed material-side fluxes. `interface_diagnostics.csv` distinguishes the crossing-flux error, adjacent-face difference, and two-sided trace jump. In the contrast sweep, `nodal_error_inf` is the direct-solve error; `cg_nodal_error_inf` is the CG error.
